Preguntas Frecuentes

¿Necesito saber programar para usar DenIA?

Para nada. DenIA está diseñado para ser "No-Code". Solo necesitas subir tu archivo Excel o PDF y escanear el código QR de WhatsApp.

¿Que requisitos debo cumplir para poder usar DenIA?

El unico requisito indispensable que debes cumplir es el entusiasmo de que tu inmobiliaria trabaje de forma automatica.

¿Puede bloquearme WhatsApp por usar esto?

Nuestra tecnología utiliza la API oficial de WhatsApp Business o protocolos de simulación humana seguros, minimizando el riesgo de bloqueos al respetar los tiempos de escritura.

¿La IA entiende audios de los clientes?

Sí, el Plan Inicial y el Plan Desarrollo incluyen transcripción de audio a texto (Whisper) para entender y responder notas de voz.

¿La IA entiende imagenes de los clientes?

Sí, el Plan Inicial y el Plan Desarrollo incluyen transcripción de imagen a texto (Whisper) para entender y responder imagenes.
